Resumo do Conceito
O SmartFin é um assistente financeiro inteligente focado no público jovem profissional. Ele não apenas registra gastos, mas utiliza modelos de linguagem (LLMs) para oferecer insights personalizados sobre hábitos de consumo e planejamento de carreira financeira.

2. Tecnologias Utilizadas
Copilot/Lovable: Para geração de código e prototipagem rápida.

React + Tailwind CSS: Para uma UI responsiva e moderna.

JSON: Para estruturação dos dados simulados.

3. Reflexão do Aprendizado
"Durante este projeto, aprendi a importância do Prompt Engineering para obter resultados precisos no desenvolvimento de software. Entendi que a IA não substitui o programador, mas atua como um 'Copiloto' que acelera a criação de protótipos funcionais e a estruturação de documentos técnicos (PRD).
